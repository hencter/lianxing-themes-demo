# 链幸智能 · 主题演示站（构建产物）

本仓库**只存放 Hugo 的构建产物**，用于 GitHub Pages 展示主题；源码在私有仓库 hencter/lianxing-themes。

- 线上地址：https://hencter.github.io/lianxing-themes-demo/
- 重新发布：在源码仓库执行 `pwsh -File scripts/publish-demo.ps1`
- 本目录内容由脚本生成，请勿直接修改

演示站包含 1 套引擎主题 + 5 套外观主题（vista / ink / paper / terminal / civic），
默认展示 lianxing-vista（程序化生成的视差美术 + Hugo 图片管线）。
仓库内的公司信息、客户名、案例与新闻均为**演示用虚构内容**。
